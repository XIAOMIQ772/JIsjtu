# 给老师写邮件

助手不能代发邮件，只起草，由用户核对后自己发送。

## 1. 问清必要信息

缺什么问什么，一次问完：

- 收件人身份（任课老师 / 助教 / 辅导员）和称呼（如“王老师”）
- 课程名称、上课时间或班级
- 用户姓名、学号（只用于落款，用户提供才写，不要编造）
- 事由与需要对方做什么、希望的时间
- 有没有证明材料（病假条、冲突的考试安排等）

能从工具补全的就自己补全：课程名和老师用 class_schedule（day=all）或 get_courses；作业名与截止时间用 get_exam；成绩明细用 get_grades。

## 2. 标题格式

【课程名】姓名-学号-事由，例如：

- 【概率统计】张三-5230XXXXXXXX-第五章作业延期申请
- 【大学物理实验】张三-5230XXXXXXXX-第 12 周实验调换申请

## 3. 正文结构

1. 称呼与问候：“王老师您好，”
2. 自我介绍一句：我是某班 / 周三 1–2 节的某某
3. 事由：事实、时间、原因，简洁具体
4. 请求：希望老师怎么做，给出可选方案（例如“能否延期到周五 23:59”）
5. 材料：附件说明（“附上校医院病假证明”）
6. 致谢与落款：姓名、学号、联系方式（用户提供才写）

语气礼貌、简短，不卑不亢，不过度道歉；不要编造理由。

## 4. 常见场景要点

- 请假：写清日期、节次、原因，说明会如何补上内容
- 作业延期：提前发，说明已完成的部分和新的期限，不要在截止后才发
- 成绩疑问：引用具体作业与得分，先请老师帮忙核对，措辞中立
- 答疑预约：给出 2–3 个自己有空的时间段（可参考 class_schedule 的空档）
- 推荐信：说明用途、截止时间、自己与该课/老师的交集，附简历

## 5. 输出

给出“标题”和“正文”两部分，正文可直接复制。提醒用户用交大邮箱（mail.sjtu.edu.cn）发送，Canvas 课程内也可以用私信。
