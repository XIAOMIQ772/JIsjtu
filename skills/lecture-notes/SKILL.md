# 课件精读与笔记

## 1. 找到课件

1. 用户没给课程 id 时，get_courses 查到课程
2. course_files（action=list）列出文件，按用户说的“第几讲/哪一章/文件名”挑选；拿不准就列出候选让用户选
3. course_files（action=download）下载（默认存到 ~/Downloads），不要用 open 弹出文件
4. 有的课程不开放“文件”页（返回 404/403），改为在公告（get_announcements）或作业说明（get_exam）里找附件链接

## 2. 阅读

- PDF 用 pdf_analysis；PowerPoint、Word、Excel（.pptx/.docx/.xlsx）用 read_office，幻灯片的讲者备注里常有老师补充的要点，不要漏掉
- 先不带页码读一遍，拿到各页开头作为目录
- 按章节分段读（每次 5–10 页，用 start_page/end_page 或 start/end），不要一次读完长文档
- 扫描版 PDF 没有文字时，如实告诉用户需要 OCR，可让用户提供文字版

## 3. 整理笔记的结构

- 本讲主题与在课程中的位置（一两句）
- 核心概念：定义 + 直观理解 + 一个最小例子
- 公式：写出公式、各符号含义、适用条件；用单行 Unicode，如 P(A|B) = P(AB)/P(B)，不用 LaTeX
- 方法与步骤：常见题型的解题步骤
- 易错点：容易混淆的概念、常见计算错误
- 与前后章节的联系
- 自测题 3–5 道（附简要答案，放在最后）

内容只来自课件和可靠常识；课件里没有、自己补充的部分标明“补充”。

## 4. 输出与保存

先在聊天里给出笔记。用户要保存时，用 write 写成 Markdown 文件，路径用用户指定的；没指定就建议 ~/Documents/课程笔记/课程名-第N讲.md 并确认后再写。
