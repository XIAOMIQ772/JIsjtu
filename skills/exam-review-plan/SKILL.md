# 考前复习规划

## 1. 收集事实（并发调用）

同时调用：

- exam_schedule：各科考试日期、时间、考场；未公布的标出来
- get_deadlines（days=21）：考前还要交的作业，避免复习时漏交
- get_time_stamp：今天是第几周、离考试周还有多久

如果考试时间大多“未公布”，按校历估计期末在第 17–18 周，并在计划里写明“按估计排，公布后用 exam_schedule 更新”。

## 2. 了解用户的情况

计划要个性化。没有说明的话，用一两个问题问清（不要一次问太多）：

- 每门课的掌握程度（没底 / 一般 / 有把握）
- 每天大概能投入多少小时
- 有没有必须保留的安排（实验、社团、实习）

用户不想回答时，用默认值：每门课按学分和距离考试的天数分配时间，每天 6 小时。

## 3. 排计划的原则

- 从最早的考试倒排；考前一天只做回顾和错题，不学新内容
- 掌握差、学分高的课分配更多时间
- 同一天最多交替两门课，每 90 分钟左右换一次科目或休息
- 截止前的作业先排进去
- 晚上 21:40 以后不排高强度任务；每周留半天机动

## 4. 资料与重点

对用户最没底的 1–2 门课：

1. course_files（action=list）找课件、往年题、复习提纲
2. course_files（action=download）下载关键文件，再用 pdf_analysis 读目录和重点页
3. 提炼该课的知识点清单：章节 → 核心概念 → 常考题型 → 易错点

数学式用单行 Unicode 书写，不用 LaTeX。

## 5. 输出

按日期列出：

- 12月28日 周一（距概率统计考试 3 天）
  - 上午：概率统计 第 4–5 章，做课件例题
  - 下午：大学物理 电磁学错题
  - 晚上：交 计算机组成 作业（23:59 截止）

结尾给出：各科考试时间汇总、需要找自习室时可用 find_classroom 或 library_status。

用户要保存计划时，用 write 写到用户指定位置；没指定就问一下，不要擅自写到别处。
