# 一周学习计划

## 1. 取数据（并发）

- class_schedule（day=this_week；用户说下周就用 next_week）
- get_deadlines（days=10，include_completed=false）
- exam_schedule（只关心这一周内的）
- get_time_stamp（确认今天是周几、第几周）

## 2. 找空档

根据课表，按天列出没课的时段（以节次为单位，参考作息：1–2 节 08:00–09:40 … 13–14 节 20:00–21:40）。今天已经过去的时段不要再排。

## 3. 分配任务

- 每项作业估一个时长（读题目说明，或问用户；默认小作业 1.5 小时、实验报告 3 小时、大作业拆成多天）
- 截止早的、分值高的优先；截止当天只留收尾和提交
- 每天安排不超过用户能接受的量（默认 4 小时课外学习）
- 周末留出复习和休息时间

## 4. 自习地点

需要具体地点时：

- find_classroom（building 选离下一节课近的楼，date 设为那一天，给出 start_period 和 end_period）找整段空闲的教室
- library_status 看各馆实时人数（只对当下有意义）

## 5. 输出

按天列出，每条写清时间、任务、地点：

- 周三 11月25日
  - 10:00–11:40 上课：网络空间安全（东中院4-201）
  - 12:00–13:40 写 概率统计 第五章作业（东中院 空教室，或主图）
  - 19:00–20:30 大学物理 第10周作业，周日 23:59 截止

最后列出“本周截止清单”（时间顺序）。用户要提醒或保存时，按用户指定的方式处理。
